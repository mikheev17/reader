# Читалка

Сервис для помощи в чтении книг и статей.

## Функциональные требования к личному кабинету

1. Главная страница с описанием возможностей ML сервиса
2. Возможность зарегистрироваться и авторизоваться
3. Возможность просматривать баланс (баланс в условных кредитах)
4. Возможность пополнять баланс через кнопку пополнить (эквайринг подключать не требуется)
5. Возможность выполнить запрос к ML сервису из Web интерфейса со списанием кредитов с баланса (при условии успешного выполнения запроса)
6. Возможность просматривать историю загруженных данных и предсказаний по ним, с указанием суммы списанных кредитов
7. Возможность выполнять запросы к ML сервису с помощью REST интерфейса
8. Требуется предусмотреть валидацию данных. Если в загружаемой выборке присутствуют ошибочные данные, то возвращать их пользователю, а над валидными данными производить предсказание
9. Требуется предусмотреть проверку на положительный баланс при запросах к системе.
10. Роль администратор подразумевает возможность пополнять баланс пользователям (модерировать пополнения от пользователей) и просматривать все транзакции.

## Функциональные возможности сервиса

1. Регистрация и логин пользователя
2. Выбор уровня английского (A1-B2)
3. Загрузка текста: txt / epub
4. Обработка текста
5. Перевод
